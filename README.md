Welcome to my **Generative AI Project Portfolio**, featuring five hands-on Python projects developed while learning to build AI applications and agents.

These projects demonstrate practical applications of Generative AI, document retrieval, AI agents, automation, and API integration.

##  Projects

### 1. Local AI Agent

A Python-based AI assistant powered by Google Gemini that helps users interact with files in a local workspace.

* **Technologies:** Python, Google Gemini, LangChain
* **Repository:** [View Project](https://github.com/pragyach20/Local-AI-Agent)

### 2. RAG System

A Retrieval-Augmented Generation system that retrieves relevant document information and uses Google Gemini to generate context-aware answers.

* **Technologies:** Python, LangChain, Google Gemini, ChromaDB
* **Repository:** [View Project](https://github.com/pragyach20/RAG-System)

An AI-powered automation project that integrates spreadsheet data, Gemini AI, and Gmail to process and summarize newly added records.

* **Repository:** [View Project](https://github.com/pragyach20/Spreadsheet-Automation)

### 4. Recipe Generator

An AI application that uses food images to identify ingredients and generate recipe suggestions.

* **Technologies:** Python, Google Gemini, Gradio
* **Repository:** [View Project](https://github.com/pragyach20/Recipe-Generator)

A Python application that integrates AI capabilities with Google Sheets for spreadsheet management.

* **Technologies:** Python, Google Gemini, Google Sheets API
* **Repository:** [View Project](https://github.com/pragyach20/Google-Sheets-Manager)
